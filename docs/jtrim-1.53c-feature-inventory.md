# JTrim 1.53c 機能インベントリ

調査日: 2026-09-26

この文書は、HTML + JavaScript で JTrim 相当の画像編集アプリを再実装するために、JTrim 1.53c の公開ドキュメント・ヘルプ由来資料・画面資料から機能面を整理したものです。

## 基準バージョン

- JTrim 1.53c
- 最終更新: 2007-10-20
- 原作者: WoodyBells
- 原版のメニューバー: ファイル / 編集 / 表示 / イメージ / カラー / 加工 / ヘルプ
- 原版は Windows 95/98/Me/NT4/2000/XP 向け
- 標準入力: BMP / JPEG / JPEG2000 / PNG / GIF / ICO
- 標準出力: BMP / JPEG / JPEG2000 / PNG / GIF
- Susie Plug-in による追加入力形式にも対応

## 操作モデル

- 画像上のドラッグで矩形選択
- 四隅のハンドルで選択範囲を調整
- Ctrl + カーソルキーで選択範囲を1px単位で移動
- Shift + カーソルキーで選択範囲を1px単位で拡大・縮小
- 選択範囲内のドラッグによる画像の移動・複写
- 多くの加工は選択範囲に限定可能
- 一部の機能は選択範囲があっても画像全体に適用
- Undo / Redo はデフォルト16段階
- Undo履歴・Redo履歴をクリア可能
- ステータスバーに座標、画素色、画像サイズ、ズーム率、色深度を表示するUIが確認できる

## Web版での再現方針

### ほぼ同等に再現可能

画像読込、D&D、新規作成、Undo/Redo、矩形選択、切り抜き、各種回転・反転、リサイズ、余白、文字、塗りつぶし、合成、連結、色補正、ヒストグラム、ほぼ全フィルタ、透過表示、保存、一括処理、サムネイル、スライドショー。

### Web API で近似可能

- クリップボード: Clipboard API（ブラウザ権限が必要）
- フォルダ一括処理: File System Access API または複数ファイル入力
- 画面キャプチャ: getDisplayMedia（ユーザーが共有対象を選択）
- 印刷: browser print
- 設定保存: localStorage / IndexedDB
- Exif: JSで読み書き
- 高品質リサイズ: 独自実装またはWASMで7方式を再現

### ブラウザでは原版どおりには再現できない

- Windowsファイル関連付け
- Windowsデスクトップ壁紙の直接設定
- TWAIN機器への直接アクセス
- Windowsのアクティブウィンドウを無許可で自動キャプチャ
- Susie Plug-in DLL の直接ロード
- 元ファイルのタイムスタンプを任意に維持して上書き

これらはUI上で「Web版では非対応」とするか、現代Web向け代替動作を提供する。

## 互換性の定義

本プロジェクトでは次の3段階を区別する。

1. **機能互換** — 同じ目的の操作ができる
2. **操作互換** — メニュー構造・ダイアログ・選択操作・ショートカットまで近づける
3. **画素互換** — 同一入力・同一パラメータから原版と同一または極めて近い画素結果を得る

公開資料だけで「機能互換」と「操作互換」の仕様面はほぼ把握できる。一方、ガウスぼかし、ソフトレンズ、パンチ、つまむ、波紋、新聞写真風などの内部アルゴリズムは公開説明だけでは完全には決定できない。そのため画素互換を目指す機能は、原版JTrim 1.53cをリファレンスとしてテスト画像を処理し、出力差分を比較するブラックボックス試験を別途行う。

## 著作権・実装方針

WoodyBells の公開利用条件では、ソフトウェアの個人・商用利用、再配布、ヘルプからの引用、画面イメージ利用等について広い利用が認められている。

ただし本プロジェクトでは以下を原則とする。

- 原版の実行コードはコピーしない
- 原版のバイナリを配布物に含めない
- 独自のHTML / CSS / JavaScript実装とする
- アイコンは独自作成または適切なライセンスのものを使用
- READMEで「JTrimの非公式Web再実装」であることを明記
- WoodyBellsおよび原版JTrimへの帰属を明記
