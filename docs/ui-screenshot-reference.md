## ツールバー外観

実機ではメニューバー直下に複数段のツールバーが配置される。

スクリーンショットから確認できる特徴:

- Windowsクラシック風の立体ボタン
- ツールバーは複数グループに分かれ、縦セパレータを持つ
- 3段構成
- メニュー項目と同一または近似の小型アイコンが多数存在
- Undo / Redo 等、状態依存でグレーアウト
- ズーム系は虫眼鏡アイコン
- スポイトが独立ボタンとして存在
- 文字入れは青い「A」
- 回転は90度表記付きアイコン
- 色変換・加工系はメニューと同じアイコン体系

正確なボタン順と機能対応は、ツールチップまたはヘルプ資料で追加確認する。

# 追補: ダイアログ実機確認（2026-09-26）

ユーザー提供の追加スクリーンショットから、以下のダイアログ仕様を確認した。

## UI再現方針の修正

本プロジェクトは **JTrimの見た目そのものをピクセル単位で複製することを目的としない**。

優先順位は次のとおり。

1. 機能の網羅性
2. コマンド名・意味・主要パラメータの互換性
3. 操作の分かりやすさ
4. JTrim利用者が迷わない情報設計
5. 必要に応じて現代的なWeb UIへ改善

Windowsクラシック風のウィジェット形状、ボタン配置、ダイアログ寸法、フォントなどは厳密再現しない。
一方で、JTrimに存在する設定項目・値域・処理方式は可能な限り維持する。

---

## リサイズ

実機画面で確認できる要素:

- 現在のサイズ表示（例: 2887 × 2887）
- 指定方法
  - サイズで指定する
  - 比率で指定する
- サイズ指定
  - 横（pixel）
  - 縦（pixel）
  - 実行履歴
- 比率指定
  - 横（%）
  - 縦（%）
  - 実行履歴
- 「縦横の比率を保持する」
- 「再サンプリングを行う」
- 再サンプリング方式
  - Box
  - Hermite
  - Triangle
  - Bell
  - Mitchell
  - BSpline
  - Lanczos3
- OK / キャンセル / ヘルプ

### Web版方針

UIはタブまたはセグメント切替でもよい。
サイズ指定・比率指定は排他的に扱う。
実行履歴は localStorage などで保持可能。
「再サンプリングを行わない」場合は nearest-neighbor 相当の処理とするか、原版挙動をブラックボックス確認する。

スクリーンショット時の表示値:
- フォント: MS Pゴシック
- サイズ: 10

- 余白: 3
- 行間: 1.0
- 不透明率: 100

※ 上記はスクリーンショット時点の値であり、すべてが初期値とは断定しない。

### Web版方針

Webフォント事情が異なるため、OSに存在しないフォントは CSS のフォールバックを使用する。
縦書きは CSS writing-mode ではなく、最終レンダリング時に Canvas 上へ描画して確定する。
文字編集確定前はプレビュー状態を保持する。

## 明るさ／コントラスト

実機画面で確認できる要素:

- 左側に画像プレビュー
- 明るさ
  - スライダー
  - 数値入力
- コントラスト
  - スライダー
  - 数値入力
- OK / キャンセル / ヘルプ
- スクリーンショット時の値は両方 0

### Web版方針

変更中はプレビューだけを更新し、OKで画像へ確定する。
キャンセル時には元画像へ完全に戻す。
Canvas API の filter に依存せず、最終的には画素演算を実装して再現性を確保する。

---

## ガウスぼかし

実機画面で確認できる要素:

- 「ぼかしのレベル (1～10)」
- スライダー
- 数値入力
- OK / キャンセル / ヘルプ
- スクリーンショット時の値: 3

### Web版方針

JTrimの公開説明では単純な数学的Gaussian blurと完全に同じとは限らないため、
当初は視覚的に近い実装を行い、後にテスト画像を用いた原版比較で画素互換を検証する。

---

## ダイアログ共通パターン

今回の実機画面から、JTrimの多くの設定ダイアログは以下の共通設計を持つことが確認できる。

- 数値項目はスピンボックス
- 連続量は「スライダー + 数値入力」の組合せ
- 画像結果を伴う色調補正ではプレビューを持つ
- OK / キャンセル / ヘルプを基本操作とする
- 設定変更中はプレビューし、OKで確定するタイプが多い

Web版ではこの思想を継承しつつ、モーダルの寸法・配置・ボタン外観は現代的にしてよい。
