## ツールバー外観

実機ではメニューバー直下に複数段のツールバーが配置される。

スクリーンショットから確認できる特徴:

- Windowsクラシック風の立体ボタン
- ツールバーは複数グループに分かれ、縦セパレータを持つ
- 3段構成
- メニュー項目と同一または近似の小型アイコンが多数存在
- Undo / Redo 等、状態依存でグレーアウト
- ズーム系は虫眼鏡アイコン
- スポイトが独立ボタンとして存在
- 文字入れは青い「A」
- 回転は90度表記付きアイコン
- 色変換・加工系はメニューと同じアイコン体系

正確なボタン順と機能対応は、ツールチップまたはヘルプ資料で追加確認する。

## 次に必要な実機資料

操作互換を高精度にするため、優先順位は以下。

### 優先度A: サブメニュー（4点）

1. ファイル → 壁紙として保存
2. 表示 → ツールバー
3. イメージ → 濃度抽出
4. カラー → ヒストグラム

### 優先度A: 基本ダイアログ

1. 新規作成
2. 保存オプション
3. リサイズ
4. 座標指定切り抜き
5. 任意角度回転
6. シフト
7. 余白作成
8. 影をつける
9. 塗りつぶし
10. 文字入れ
11. 合成
12. 連結

### 優先度B: 色調整ダイアログ

- 明るさ／コントラスト
- RGBの度合い
- ポスタライズ
- ソラリゼーション
- ガンマ補正
- HSVカラー調整
- 2階調化
- グラデーション
- シャドウ・ハイライトの明るさ
- 色解像度の変更
- 単色カラースケール

### 優先度B: 加工ダイアログ

「...」の付く加工項目を中心に、パラメータ値域・チェックボックス・プレビュー方式を確認する。

特に:
- ソフトレンズ
- シャープにする
- エンボス
- エッジの強調
- エッジを抽出
- ガウスぼかし
- モザイク
- オイルペイント
- 渦巻き
- パンチ
- つまむ
- スポットライト
- 超新星
- 波紋

### 優先度C: 独立ウィンドウ

- サムネイル表示

- スライドショー
- 画面キャプチャ
- 印刷プレビュー

### ツールバー対応表

各ツールバーボタンにマウスを載せて表示されるツールチップが分かれば、スクリーンショットのボタン順とコマンドを1対1で特定できる。

## 実装時のUI基準

原版の見た目をそのままピクセルコピーするのではなく、以下を優先する。

1. メニュー階層と表示順
2. コマンド名とショートカット
3. 有効/無効状態
4. ダイアログの項目・値域・既定値
5. 選択範囲やプレビューの操作感
6. ツールバー配置
7. Windowsクラシック風の視覚表現

これにより、ブラウザ上でも「触るとJTrim」と感じる操作互換を目指す。
